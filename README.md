**Reprise** is a lightweight Windows app that lets you save the last 30 seconds of a game or application with a single keypress.
Trim, crop, adjust audio, or add captions in the editor, then save your changes back to the same clip.

- [Download Reprise](https://github.com/NinefoldFable/Reprise/releases/latest)
- [Benchmarks and FAQ](https://aevraen.xyz/reprise)

## Quick start

1. Download and run the installer from **Releases**.
2. Open **Reprise** from the Start menu and choose **Set up replay**.
3. Press **Page Down** to clip the last 30 seconds.
4. Click **Open clips folder** to find your recordings.

Reprise targets **Windows 11 x64**. Linux and MacOS releases are planned, but not yet public.
This repository hosts Reprise downloads and release notes.

<p><sub><i>You can change the clipping hotkey, save location/folder, and other settings as soon as you've completed setup and opened Reprise.</i></sub></p>
